# Portfolio Development Rules

## Goal

Build a premium portfolio representing a 3-year Full-Stack Software Developer.

## Positioning

Full-Stack Software Developer
React / Next.js / TypeScript / Node.js / PostgreSQL / Redis / AI

## Rules

- No fabricated metrics
- No fake clients
- No fake experience
- No fake contributions
- No claiming upstream open-source work as original
- Preserve open-source attribution
- Verify licenses before reuse
- Clearly document personal contributions
- Use real implementation details only
- Keep the website production-quality
- Prioritize performance and accessibility
- Avoid generic portfolio patterns
